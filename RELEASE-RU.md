# Готовность к запуску — 18 сентября 2026

## Подтверждено

- Автотесты расчётов, истории, кэша, локализации и ошибок проходят.
- TypeScript проверен. Переносимая production-сборка выполнена в отдельной копии без внутренних настроек среды. Установленные зависимости переиспользованы; установка на чистой Windows не проверялась.
- Избранные монеты CoinGecko берутся из полного каталога, а не только из текущей страницы.
- Более 40 запрошенных монет разбиваются на допустимые пакеты. Признак устаревания сохраняется для объединённого ответа.
- Обновление сохраняет данные текущей пары; при сбое они помечаются устаревшими. При выборе другой пары старые данные не подставляются.
- Журнал сервера фиксирует домен источника, HTTP-статус или тип сетевого отказа, без ключей и содержимого ответов.

## Обязательные проверки перед обещанием полной работоспособности

```sh
pnpm test
pnpm typecheck
pnpm build
pnpm start
```

В другом терминале, указав фактический адрес запущенного сервера:

```sh
pnpm verify:live -- http://127.0.0.1:8787
```

Можно указать URL своего доступного хостинга. Проверка не обходит авторизацию: закрытый Sites URL требует обычного авторизованного доступа, иначе команда завершится ошибкой. `verify:live` проверяет 11 сценариев: свежие фиатные курсы, каталог, месячную/годовую историю, BTC/ETH, криптоисторию и CoinGecko. Резервный снимок, устаревшие данные, пустые/некорректные графики и HTTP-ошибки считаются провалом. Ненулевой код завершения блокирует выпуск в CI.

Параметр `--without-coingecko` годится только для диагностики ограниченной конфигурации и НЕ подтверждает полную готовность.

## Незакрытые блокеры

1. Серверный `COINGECKO_DEMO_API_KEY` не настроен. Создайте свой Demo-ключ и добавьте его как секрет хостинга. Для локальной работы используйте `.env`; не коммитьте файл. Документация: https://docs.coingecko.com/demo/reference/authentication .
2. В журналах опубликованной версии обнаружены ответы 502 для Coinbase BTC/ETH. Новый журнал `market_upstream` позволяет отличить HTTP-отказ поставщика от сетевого сбоя. Без исправления доступности или подключения другого подтверждённого источника работа Coinbase не считается проверенной.
3. Локальный запуск Wrangler в проверочной контейнерной среде прерван системной ошибкой `uv_interface_addresses`. Переносимая сборка успешна, но это не подтверждение запуска на любом компьютере. На целевой машине нужно выполнить команды выше.

Не маркируйте релиз как полностью готовый только по успешной сборке или доступности главной страницы. Полная готовность требует успешного получения актуальных данных на выбранном хостинге и повторной проверки после подключения ключа.
