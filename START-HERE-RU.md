# FluxRate — полные исходники

## Что находится в архиве

- `app/` — страницы React/TypeScript (TSX), разметка интерфейса, CSS, серверный API.
- `lib/` — источники курсов, точная арифметика, 15 языков, обработка графиков.
- `public/` — логотип FluxRate, локальные SVG-флаги и криптологотипы, лицензии.
- `components/`, `hooks/`, `vendor/` — компоненты интерфейса и стили.
- `scripts/`, `build/` — сценарии запуска и сборки.
- `tests/` — проверки графиков, переводов и чисел.
- `package.json`, `pnpm-lock.yaml` — зависимости с закреплёнными версиями.
- `.env.example` — названия переменных окружения без секретов.
- `dist/` — проверенная сборка: браузерные JS/CSS и серверный Worker. Эта папка добавляется в ZIP после сборки.

Это полноценное веб-приложение, **не автономная статическая HTML-страница**. HTML создаётся из TSX при работе приложения. Двойной щелчок по файлу не запустит API и получение курсов. Для разработки нужен Node.js; для публикации — среда, поддерживающая серверную часть/Cloudflare Workers. Выкладка только папки `dist/client` на обычный статический хостинг не сохранит функциональность API.

## Запуск на компьютере

1. Установите Node.js 22.13 или новее и pnpm версии, указанной в `package.json`.
2. Распакуйте ZIP. Откройте терминал в папке `FluxRate`.
3. Выполните:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

4. Откройте адрес, выведенный в терминале (по умолчанию порт 5173).

Для локальной работы не нужен доступ к аккаунту автора. Профиль среды определяется автоматически; внутренние настройки среды разработки и зависимости `node_modules` в архив не включены.

## Переменные окружения и реальные котировки

Создайте `.env` по образцу `.env.example`. CoinGecko требует ваш собственный `COINGECKO_DEMO_API_KEY`; держите ключ только на сервере. Без него используется доступный каталог Coinbase, а раздел CoinGecko показывает сообщение о настройке. Frankfurter и NBP используются для обычных валют. Доступность данных зависит от API, сети и лимитов источника.

`lib/data/nbp-snapshot.json` содержит реальные сохранённые публикации NBP с исходными датами. Это резерв при недоступности API, **не актуальный live-поток**. Сохранённые данные помечаются как устаревшие, когда необходимо.

## Сборка и проверки

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm start
```

Последняя команда запускает локальную проверку собранного Worker; адрес выводится в терминале. Если содержимое `dist` было собрано на другом компьютере, сначала выполните `pnpm build`: так конфигурация путей будет соответствовать вашей системе. Ключи для рабочего хостинга задаются отдельно в его настройках. `pnpm start` — локальный эмулятор Cloudflare Workers, а не production-сервер Node.js для Render/Railway. Для такого Node-хостинга нужна адаптация серверной сборки. Текущая сборка публикуется в Sites / совместимую среду Workers.

Результаты аудита перечислены в `AUDIT-RU.md`; текущие блокеры и команда проверки живых API — в `RELEASE-RU.md`.

## Языки и графика

15 языков: английский, русский, украинский, испанский, польский, немецкий, французский, итальянский, португальский, нидерландский, чешский, румынский, греческий, турецкий, арабский. Арабский включает RTL и поддержку арабских цифр в сумме и комиссии. Переводы можно редактировать в `lib/i18n.ts` и `lib/locales.ts`.

Флаги показывают код валюты. Евро обозначено флагом ЕС, общие региональные валюты — нейтральным глобусом. Криптовалюты используют единые монохромные значки; для неизвестного символа предусмотрена монограмма. Источники и лицензии графики: `public/assets/ATTRIBUTION.md`.

Архив не содержит паролей, API-ключей, `node_modules`, истории Git и настроек входа. Идентификатор существующего проекта Sites в `.openai/hosting.json` не является секретом и сам по себе не даёт доступа к сайту.
